后量子密码机 · 业务流程演示

AXU3EGB（Zynq UltraScale+）· 密钥在 TEE 里管 · 运算在 FPGA 里做 · 应用经命令行 / HTTP 接口调用

TEE（OP-TEE TA）生成种子与对称密钥（熵 = OP-TEE PRNG ⊕ PL TRNG），用 KEK 包成 blob；需要时解开、经安全通路装进 FPGA。KEK 不出 TA。
FPGA（PL）ML-KEM、ML-DSA、AES / SM4、SM3、真随机数。私钥每次现展开、算完由硬件擦；对称密钥在金库里无读出路径。
普通世界（Linux）daemon 调度与接口（SDF / PKCS#11 / 远程 mTLS）。手里只有句柄与密文 blob，没有任何明文密钥。

一 密钥管理

生成一把 SM4 数据密钥

$ hsmctl keygen sm4 data-key
已生成 SM4 密钥「data-key」→ /tmp/hsm-demo/keystore/data-key.key
  密钥：60 字节 blob（TA 用 KEK 包裹的密文，本机以外解不开）
  1. TEETA 生成 16 字节对称密钥（熵 = OP-TEE PRNG ⊕ PL TRNG），用 KEK 包成 60 字节 blob
  2. TEE→PL密钥经 PTA → EL3 写进 PL 对称金库槽 3（普通世界不经手）
  3. PL会话结束：PQC 展开区、对称金库与三个分组核已发擦除

密钥由 TA 生成（熵来自 OP-TEE PRNG 与 FPGA 里的真随机数），应用拿到的只是包裹后的 blob。

生成一对 ML-DSA-65 签名密钥

$ hsmctl keygen mldsa65 signer
已生成 ML-DSA-65 密钥「signer」→ /tmp/hsm-demo/keystore/signer.key
  公钥 1952 字节（可公开）
  私钥（种子）：76 字节 blob（TA 用 KEK 包裹的密文，本机以外解不开）
  1. TEETA 生成 ML-DSA ξ 种子（熵 = OP-TEE PRNG ⊕ PL TRNG），用 KEK 包成 76 字节 blob 交回
  2. TEE→PL种子经 PTA → EL3 写进 PL 暂存口（daemon 手里只有 blob）
  3. PLML-DSA-65 生成密钥对：1.83 ms（私钥在 PL 展开区现展开，算完由硬件擦）
  4. NWdaemon 交出句柄 0 的种子 blob（76 字节密文，它自己解不开）
  5. PL会话结束：PQC 展开区、对称金库与三个分组核已发擦除

生成一对 ML-KEM-768 密钥封装密钥

二 数据加解密（SM4-CBC）

准备一份业务数据

$ printf '采购合同 PO-2026-1010\n甲方：示例公司\n金额：人民币 100,000.00 元\n交付：2026-12-31\n' > contract.txt; cat contract.txt
采购合同 PO-2026-1010
甲方：示例公司
金额：人民币 100,000.00 元
交付：2026-12-31

加密

$ hsmctl encrypt data-key contract.txt contract.enc
SM4-CBC 加密：明文 102 字节 → 密文 128 字节（16 字节 IV + 112 字节）
  1. TEETA 用 KEK 解开 60 字节 blob（认证通过）
  2. TEE→PL密钥经 PTA → EL3 写进 PL 对称金库槽 3（普通世界不经手）
  3. PLTRNG 取 16 字节（8 路环振 + SP 800-90B 健康检测）
  4. PLSM4-CBC 加密 112 字节：7 个分组逐个在 PL 里算，密钥取自金库槽 3（0.12 ms）
  5. PL会话结束：PQC 展开区、对称金库与三个分组核已发擦除

00000010  7d 8c 60 c4 0d 46 59 fe  b4 d3 72 46 e4 90 7b ec  |}.`..FY...rF..{.|

每次加密：TA 解开 blob、经安全通路把密钥装进 FPGA；之后每个分组都在 FPGA 里算，不再进 TEE。

解密并比对

$ hsmctl decrypt data-key contract.enc contract.dec
SM4-CBC 解密：密文 128 字节 → 明文 102 字节
  1. TEETA 用 KEK 解开 60 字节 blob（认证通过）
  2. TEE→PL密钥经 PTA → EL3 写进 PL 对称金库槽 3（普通世界不经手）
  3. PLSM4-CBC 解密 112 字节：7 个分组逐个在 PL 里算，密钥取自金库槽 3（0.12 ms）
  4. PL会话结束：PQC 展开区、对称金库与三个分组核已发擦除
$ cmp contract.txt contract.dec && echo '解密结果与原文逐字节一致'

八 应用经 HTTP 接口调用（本机 127.0.0.1:8080）

上层应用不链 libsdfe，发 JSON 就行。网关 hsm_httpd 与 hsmctl 共用同一套业务代码，

密钥一样在 TEE 里管、运算一样在 FPGA 里做。板上没有 curl，这里用 nc 直接发原样 HTTP 请求：

$ sed -n 2,5p http
m=$1; p=$2; b=${3:-}
n=$(printf %s "$b" | wc -c)
{ printf '%s %s HTTP/1.1\r\nHost: 127.0.0.1\r\nContent-Type: application/json\r\nContent-Length: %d\r\nConnection: close\r\n\r\n' "$m" "$p" "$n"
  printf %s "$b"; } | nc 127.0.0.1 8080 | tr -d '\r' > "$(dirname "$0")/last.raw"
