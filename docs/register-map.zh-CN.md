# 加速器寄存器映射

本文是软件侧加速器后端（`src/hal/`、`include/pqchsm/accel.h`）与硬件加速器
（`hardware/rtl/bus/`）之间的契约。两侧都照它实现，cocotb 测试台
`hardware/tb/cocotb/test_axi.py` 逐条验证其中的每一款。

控制面走 AXI4-Lite，数据面走 AXI4-Stream。AXI 是 ARM 的公开标准，不是厂商接口，
因此实现它的 RTL 与算法核一样可移植：纯可推断 Verilog，未实例化任何厂商 IP 或
互连原语。

## 地址映射

所有寄存器均为 32 位、按字对齐。地址译码只看 `[4:2]` 位。

| 偏移 | 名字 | 软件权限 | 说明 |
|---|---|---|---|
| `0x00` | `CTRL` | 只写 | `[0]` START，`[1]` SOFT_RESET |
| `0x04` | `STATUS` | 只读 | `[0]` DONE，`[1]` BUSY，`[2]` ERR |
| `0x08` | `MODE` | 读写 | 操作码 |
| `0x0C` | `PARAM` | 读写 | 参数集 |
| `0x10` | `IN_LEN` | 读写 | 输入字节数 |
| `0x14` | `OUT_LEN` | 只读 | 输出字节数，由硬件回填 |
| `0x18` | `ERRCODE` | 只读 | 出错细分原因，由硬件回填 |
| `0x1C` | `VERSION` | 只读 | 常量 `0x0001_0000` |

## 行为契约

**START 自清。** 向 `CTRL[0]` 写 `1` 触发一次命令，硬件在同一周期把该位清掉，
`CTRL` 读回恒为 `0`。若不自清，软件任何一次对 `CTRL` 的读改写都会重新触发命令。

**SOFT_RESET 同样自清。** 它复位数据通路、状态位与两侧流指针，
不影响 `MODE`/`PARAM`/`IN_LEN`。

**DONE 是电平锁存，不是脉冲。** 命令完成时置位，一直保持到下一次 START。
软件在任意时刻轮询 `STATUS`，1 周期脉冲会被漏采。清除时机绑定在 START 而不是
"读 `STATUS`"上，因此读寄存器不会把它所报告的状态本身弄没。

**ERR 与 DONE 同时置位。** 失败的命令在同一周期置起两者，并把细分原因留在
`ERRCODE` 里。软件不需要另外轮询一条"失败"路径。

**BUSY 反映数据通路**而不是锁存位：从 START 到完成期间为高。

**STATUS、OUT_LEN、ERRCODE 由硬件写，软件只读。** 对它们的写入被忽略，
响应仍为 `OKAY` 而不是 `SLVERR`：AXI4-Lite 上写只读寄存器是良性操作，
返回错误反而会让不了解该约定的主机停在错误处理里。

**未映射地址**读返回零、写被忽略，响应一律 `OKAY`。由于译码只看 `[4:2]`，
`0x20` 及以上会回绕到同一组寄存器；可达范围由系统分配的地址空间大小限制。

## 操作码

| 编码 | 操作 | `IN_LEN` | `OUT_LEN` |
|---|---|---|---|
| 7 | NTT 正变换 | 512 | 512 |
| 8 | NTT 逆变换 | 512 | 512 |
| 9 | Keccak-f[1600] | 200 | 200 |

其余编码，或与编码不匹配的长度，都会以 `ERR` 置位、`ERRCODE = 3`（该模式未实现）
结束。如实报错是有意的：悄悄回落到另一种实现会让只做了一部分的加速器看起来
像是完整的。

`accel_mode_t` 里余下的编码——完整的 ML-KEM 与 ML-DSA 操作——在软件头文件中已定义，
由软件后端实现，但没有硬件实现，正是这些编码会返回 `ERRCODE = 3`。

## 数据面

数据面位宽 32 位。缓冲区按字寻址，字节序为小端，与软件侧一致。

**输入。** 每个 AXI4-Stream 包从缓冲区偏移 0 开始写；带 `TLAST` 的一拍被接受后，
写指针归零，下一个包重新从头开始。软件因此不需要单独的"复位写指针"寄存器。
`BUSY` 置位期间 `TREADY` 为低：命令执行中不接收新输入。

**输出。** 命令完成后，`OUT_LEN` 换算成的字数即可读取。拉高 `TREADY` 把结果取走，
最后一拍带 `TLAST`。取完读指针归零、`TVALID` 落下，因此结果只能取一次；
需要再取就得重新发一次命令。

## 命令时序

```
送入数据流（最后一拍带 TLAST）
写 MODE
写 IN_LEN
写 CTRL = START
轮询 STATUS 直到 DONE
若 ERR：读 ERRCODE
否则：  读 OUT_LEN，然后把输出流取走
```

这与 `src/hal/` 里软件后端遵循的时序完全相同，也正因如此，软件桩、Verilator
仿真出来的 RTL、以及将来的内存映射 transport 在 `pqc_backend_t` 之下可以互换。

## 验证

`hardware/tb/cocotb/test_axi.py` 逐条覆盖上述条款——复位取值、`VERSION` 常量、
读写寄存器、字节选通、START 自清、只读寄存器、DONE 锁存、未实现的操作码、
两条数据通路与 Python 参考模型的比对、流握手空拍、`BUSY` 关闭输入流、
以及 SOFT_RESET。AXI 总线功能模型在测试台里手写，不引入任何第三方 AXI 库。
